## y q hace cada cosa??

**01. Clases y objetos**

se crea la clase Persona con nombre, edad y el metodo mostrarInfo(). tambien hay varios objetos para probar q funciona.

**02. Encapsulamiento**

se usan atributos privados, getters y setters en Java. en Python se usan atributos con guion bajo y metodos para acceder y modificarlos.

**03. Herencia**

aca aparecen Persona y Estudiante. Estudiante hereda de Persona y agrega el atributo carrera.

**04. Polimorfismo**

se trabaja la sobrecarga de metodos en Java y la sobrescritura de metodos en ambos lenguajes.

en Python se usa `*args` para simular la sobrecarga pq no funciona igual q en Java.

## q toca hacer ahora??
